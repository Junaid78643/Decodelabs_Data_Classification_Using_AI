# Data Classification Using AI

This project demonstrates a basic supervised learning workflow using a small dataset.

## Overview

- Load and inspect a dataset
- Split it into training and testing sets
- Train a simple classification model
- Evaluate the model's performance

## Dataset

The project uses the classic Iris flower dataset from scikit-learn.

## Requirements

- Python 3.10+
- pandas
- scikit-learn

## Setup

```bash
pip install -r requirements.txt
```

## Run the project

```bash
python classifier.py
```

## Result

The script prints:

- dataset shape
- first rows of data
- summary statistics
- class distribution
- train/test split details
- model accuracy
- classification metrics

This is a simple beginner-friendly example of machine learning classification.
